# BUG-001: problem_user sees the same product image on every item

**Severity:** Medium  
**Status:** Open / Documented with Expected Failure (`test.fail`)  
**Environment:** `saucedemo.com`, Chrome & Firefox, standard desktop viewport  

## Steps to Reproduce
1. Navigate to `https://www.saucedemo.com/`
2. Log in with credentials:
   - Username: `problem_user`
   - Password: `secret_sauce`
3. Observe the product catalog images on the inventory page (`/inventory.html`)

## Expected Result
Each product card displays its distinct, corresponding product image (e.g., backpack, bike light, bolt t-shirt, etc.).

## Actual Result
All product cards on the inventory page display the exact same image (`/static/media/sl-404.168b1cce.jpg`, a picture of a dog).

## Evidence & Automated Test Reference
- **Automated Test:** [`tests/ui/all-users.spec.ts`](../tests/ui/all-users.spec.ts)
- **Assertion:**
  ```typescript
  test.fail(name === 'problem', 'BUG-001: problem_user sees the same image for every product');
  const sources = await inventory.getImageSources();
  expect(new Set(sources).size).toBe(sources.length);
  ```
- **Why `test.fail()` is used:** Marking this known defect with `test.fail()` documents the bug in code and prevents false alarms in CI while ensuring that if the bug is ever resolved upstream, the test will fail until the expectation is updated.
